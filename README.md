# 🏥 Dr. Sharma Clinic

An interactive, responsive web application designed for **Dr. Sharma Clinic** to streamline patient management, showcase clinical services, and provide online appointment booking by call or by whatsapp.

---

## 🌟 Features

- **Online Appointment Booking:** Easy-to-use form for patients to schedule consultations online.
- **Service Showcase:** Detailed information on clinic specializations, medical procedures, and diagnostic services (e.g., ECG).
- **Doctor Profile:** Overview of qualifications, experience, and certifications.
- **Interactive UI:** Smooth navigation built with clean HTML5, CSS3, and modern JavaScript.
- **Responsive Design:** Optimized for seamless viewing across mobile, tablet, and desktop devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Assets:** Visual media showcasing clinic facilities, services, and achievements
